About ProAppStore

A marketplace for premium web apps. One SDK, one subscription, full power. Built for developers who want to ship real products without managing infrastructure.

What is ProAppStore?

ProAppStore is the paid counterpart to FreeAppStore. Where FreeAppStore provides free, open-source apps with local storage, ProAppStore gives developers the full backend stack: per-app SQL databases, file storage, real-time WebSockets, Stripe subscriptions, maps, and more.

Developers build with a single SDK (@proappstore/sdk) and get hosting, auth, payments, and databases out of the box. Users get a single $9/month subscription that unlocks every app on the platform.

Our Vision

We believe the next generation of software is web-native. No app store gatekeepers, no 30% tax, no install friction. ProAppStore is the infrastructure layer that makes it possible for indie developers to build and monetize serious web apps without managing servers, databases, or payment systems.

How It Works

For Developers

Run pas create my-app. Get a repo, database, hosting, and auth in 30 seconds. Push to main to deploy. The SDK handles everything else.

For Users

Sign in once with GitHub. One $9/month subscription unlocks every Pro app. No per-app purchases, no surprise charges.

For the Platform

10% commission on developer-set subscription prices. Developers keep 90%. Stripe handles all payment processing.

Platform Architecture

Every Pro app runs on Cloudflare's global edge network. The platform provides:

  • Auth — GitHub OAuth, shared identity across all apps. Sign in once, use everywhere.
  • Database — Per-app Cloudflare D1 (SQLite). Your own tables, indexes, joins. Accessed through a dedicated data worker.
  • Storage — R2 file storage for images, videos, documents. Public and private uploads.
  • Real-time — WebSocket rooms via Durable Objects. Chat, presence, multiplayer.
  • Payments — Stripe checkout, billing portal, webhooks. Platform handles the plumbing.
  • Maps — Geocoding, reverse geocoding, map embeds. OpenStreetMap-powered, no API keys needed.
  • Hosting — Cloudflare Pages with automatic deploys on git push. Zero config.

The Free/Pro Relationship

FreeAppStore and ProAppStore share the same identity system and SDK lineage. @proappstore/sdk extends @freeappstore/sdk with additional modules. Apps on either platform use the same auth, KV storage, counters, rooms, and proxy features.

The difference: Pro apps get per-app SQL databases, file storage, Stripe subscriptions, maps, and uncapped real-time rooms. Free apps run with sensible limits that keep the platform sustainable.

Tech Stack

  • TypeScript, React 19, Vite 8, Tailwind CSS 4
  • Cloudflare Workers, D1, Durable Objects, R2, Pages
  • Stripe for payments
  • pnpm workspaces, OIDC trusted publishing to npm
  • Node 22+ (CI uses Node 24)
