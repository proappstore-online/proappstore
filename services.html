How it works

1. Sign in & top up

Create a free account (GitHub sign-in). Add at least $10 to your balance via Stripe. Your money sits in your account until a developer works — unused balance stays yours.

2. Find a developer or post a request

Browse: Check the developer directory below. See their rate, quality score, portfolio, and ratings. Click “Hire” on the one you like.

Post: Describe what you want built. Developers see your request and the best match accepts.

3. Chat & build

You and the developer communicate through the service chat. Describe features, give feedback, ask questions — your messages are free. Every developer message costs their listed rate. Each message advances the project: writing code, setting up databases, configuring deploys.

4. Ship & rate

When the app is done, the developer marks it delivered. You rate the experience (1–5 stars). The app is live on your subdomain, source code in your GitHub repo.

Every developer sets their own per-prompt rate. You see it before you hire. Here’s what real apps cost:

Simple tool — $15–$30

A timer, calculator, or single-purpose utility. 15–30 developer messages at $1/prompt.

Example: “Build me a Pomodoro timer with sound alerts and a daily stats page.”

Small app — $30–$80

A booking system, task board, or portfolio site with a database. 30–80 prompts.

Example: “A dog walking booking app — owners post walks, walkers claim them, both get push notifications.”

Full product — $80–$200+

A marketplace, social app, or business tool with auth, real-time features, file uploads, and maps. 80–200+ prompts.

Example: “A car classifieds site — sellers post listings with photos, buyers filter by make/price/location, each listing has a map.”

Questions

What if I don’t like what the developer built?

You can cancel the engagement at any time. You only pay for messages already sent. If there’s a dispute, contact support — we have an admin refund process.

Can I set a budget limit?

Yes — your balance is your budget. When it hits $0, the developer can’t send more messages (and therefore can’t charge you). Top up only when you’re ready for more work.

What tech stack do the apps use?

All apps are built with the ProAppStore SDK — React frontend, Cloudflare Workers backend, D1 database, R2 file storage, WebSocket rooms, push notifications, maps, and AI. It’s a full-stack platform.

Can I hire multiple developers?

Yes. You can have up to 5 active engagements at once. Each has its own chat and billing.

How long does it take?

Depends on the app. A simple tool can be done in a day. A full product might take a week. You set the pace — the developer works when you give feedback.

Do I need to know how to code?

No. You describe what you want in plain English. The developer translates it into code. You review the live app, not the source code.

What happens after the app is built?

It’s live at yourapp.proappstore.online. You own the source code (GitHub). Updates deploy automatically on push. If you want changes later, hire the same developer (or a different one) for another round.
