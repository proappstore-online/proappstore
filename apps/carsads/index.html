About

Carsads is a car classifieds marketplace. List your car with photos, specs, and a price. Browse listings filtered by make, model, year, price range, and location. Each listing gets a dedicated page with an embedded map showing the seller's area.

Sellers upload multiple photos per listing (stored on R2), write detailed descriptions, and set their asking price. Buyers can see all active listings in a responsive grid, filter and sort by what matters, and contact sellers directly.

The embedded maps use the platform's geocoding API (OpenStreetMap-based) — no Google Maps keys needed. Every listing is automatically geocoded from the seller's city or postcode.

Carsads is a Pro app on ProAppStore. It uses the ProAppStore SDK for authentication, real-time features, and data storage. The source code is available on GitHub.
