About

Loopride solves the problem of recurring trips — school runs, commute shares, weekly errands. Set up a route with pickup and dropoff points, choose which days and times, and your driver follows the same schedule every week.

Routes are geocoded using the platform's maps API. Driving directions render as a real route on the map (not a straight line). When a trip starts, the driver's GPS position is tracked live and shared with passengers via WebSocket rooms.

Designed for small groups who ride together regularly. Not a ride-hailing service — no surge pricing, no matching algorithms, no marketplace dynamics. Just a shared schedule for people who already know each other.

Loopride is a Pro app on ProAppStore. It uses the ProAppStore SDK for authentication, real-time features, and data storage. The source code is available on GitHub.
