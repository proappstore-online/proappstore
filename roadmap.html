Roadmap

What we've shipped, what we're building, and where we're headed. Updated live as things land.

Shipped

SHIPPED

SDK v1.7 — Full platform SDK

Auth, KV, counters, rooms, proxy, per-app SQL database, file storage, maps, subscriptions, license keys. React hooks API (useProAuth, useProSubscription, useProGate) and ProShell component.

SHIPPED

CLI — pas create

One command scaffolds a full Pro app: React + Vite + Tailwind project, provisions D1 database, connects to platform auth.

SHIPPED

Per-app SQL Database

Each app gets its own Cloudflare D1 database fronted by a data worker. Custom schema, indexes, joins. SDK: app.db.query(), app.db.execute(), app.db.batch().

SHIPPED

File Storage (R2)

Upload images, videos, documents. Public files get direct URLs for <img src>. SDK: app.storage.upload(), app.storage.uploadPublic(), app.storage.download().

SHIPPED

Maps + Geocoding

Address-to-coordinates, reverse geocoding, map embeds. OpenStreetMap/Nominatim powered. No Google API keys. SDK: app.maps.geocode(), app.maps.embedUrl().

SHIPPED

React Hooks API

useProAuth, useProSubscription, useProGate — apps own their UI. Import from @proappstore/sdk/hooks.

SHIPPED

Dashboard + Console

User account management at dashboard.proappstore.online. Creator console at console.proappstore.online.

SHIPPED

Platform Auth (GitHub SSO)

One sign-in across all Free and Pro apps. FAS handles identity, PAS delegates. Shared token format.

SHIPPED

OIDC Trusted Publishing

SDK and CLI publish to npm via OIDC from GitHub Actions. No stored npm tokens.

Centralized API key vault. Users add their AI keys (OpenAI, Anthropic, Google) once. Apps call AI through a server-side proxy. Developers never see user keys. Token usage billed at cost.

PLANNED

Cron / Scheduled Workers

Run background jobs on a schedule. Digests, reminders, batch processing, daily challenges.

PLANNED

Transactional Email

Send emails from your app. Welcome messages, notifications, receipts. Quota included with Pro subscription.

PLANNED

Custom Domains

Bring your own domain to your Pro app. CNAME setup, automatic SSL, DNS verification.

PLANNED

Developer Payouts

PLANNED

App Analytics

Long-term Vision

The Full-Stack Web App Platform

ProAppStore is building toward a world where any developer can ship a production-grade web app in an afternoon. Not a toy. Not a demo. A real product with auth, databases, payments, storage, real-time features, and global edge hosting.

The platform handles the 80% of infrastructure that's the same for every app. Developers focus on the 20% that makes their app unique.

This roadmap is a living document. Priorities shift based on what developers need most. Have a feature request? Open an issue.
