Platform features

All Pro apps share these capabilities through one SDK. Read the docs →

Per-app SQL Database

Full D1 access. Custom schema, indexes, joins. Your own isolated database.

Auth (GitHub + Google + Email)

Platform-level sign-in. One account across all Pro apps.

Real-time Rooms

WebSocket fan-out. Chat, presence, multiplayer. Uncapped on Pro.

Stripe Subscriptions

Checkout, billing portal, webhooks. Platform handles all payment flows.

Per-user KV + Counters

User storage + shared atomic counters for votes, views, leaderboards.

File Storage (R2)

Upload images, videos, documents. 50 MB per file. SDK: app.storage.upload().

Maps + Geocoding + Routing

Geocode addresses, driving directions, embed maps. OpenStreetMap powered, no Google keys.

Push Notifications

Web Push via VAPID. Subscribe users, send targeted or broadcast pushes.

SMS

Twilio-backed text messages. Send reminders, confirmations, broadcasts. Creator-only.

Server-side AI

Workers AI text generation, chat, and embeddings. Two model tiers, included in subscription.

ProShell + Hooks

Platform auth gate + subscription wall. ProShell or hooks — you control the UI.

Build an app in 60 seconds

Two commands. You get a database, auth, file storage, maps, AI, and auto-deploy. Start with Claude Code, Cursor, or any AI tool.

How creators get paid

One subscription, every app — fairly split by usage.

No per-app prices

$9/mo unlocks every Pro app. Creators don't set a price; you don't pick which app to pay for.

Pool split by usage

Each month, your $9 (minus the 10% platform fee) is divided across the apps you actually used, proportional to how much you used each one.

Spotify-style payouts

A creator's monthly payout = the sum of their slice from every subscriber who used their app. Land in their Stripe Connect account at month end.

What that means for builders

Don't gate features. Don't show upgrade prompts. Build something people use — your earnings track usage, nothing else.
